# 📱 Aplikasi Manajemen Aktivitas Mahasiswa (MAS)

> Aplikasi *mobile* dan *desktop* berbasis **React Native (Expo)** yang dirancang khusus untuk membantu mahasiswa dalam mengelola tugas akademik, jadwal kuliah, pencatatan keuangan harian, serta produktivitas secara terpusat.

---

## 🚀 Fitur Utama
- **Manajemen Tugas & Jadwal:** Mencatat tenggat waktu (*deadline*) tugas kuliah dan mengatur jadwal harian agar tidak ada yang terlewat.
- **Pencatatan Keuangan:** Memantau pemasukan dan pengeluaran harian mahasiswa secara praktis.
- **Tampilan Responsif:** Dioptimalkan agar berjalan dengan mulus dan lancar di berbagai platform, baik perangkat *mobile* maupun *desktop*.
- **Antarmuka Minimalis:** Dibangun dengan desain yang bersih dan intuitif untuk pengalaman pengguna yang nyaman.

---

## 🛠️ Tech Stack
- **Framework:** React Native / Expo
- **Bahasa:** JavaScript / TypeScript
- **Styling:** React Native StyleSheet / Custom UI Components
- **Version Control:** Git & GitHub
